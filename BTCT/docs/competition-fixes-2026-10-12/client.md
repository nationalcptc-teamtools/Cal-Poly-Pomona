## New invariants (for CLAUDE.md "Critical invariants" and README "Conventions & invariants")

1. **An empty page fragment is seeded only through `seedPageFragment`** (`src/lib/page-seed.ts`), never `applyTemplate`: the seed's Yjs client id is derived from the page id and the markdown, so two clients seeding the same text at once produce one copy.
2. **A body rewrite (version restore) waits for the provider's own sync.** Use `whenServerSynced` / `restorePageVersion`; `whenFullySynced` also resolves on a 3 s timer and must never authorize a rewrite.
3. **Only the client whose transaction changed a collaborative Y.Text writes it back to the record, and only that field.** Never write a whole record from a bystander's copy.
4. **Note images: retire late, un-retire always.** A removal retires after `RETIRE_DELAY_MS` (10 s) and only on the removing client; any insert of an `asset_image` whose asset is retired un-retires it. The `asset_image` parse rule must stay above Crepe's `img[src]` rule (`priority: 60`).
5. **A page delete logs the whole subtree in one entry, and restore re-adds it in one transaction followed by `seedMissingYTexts`.** The change log is capped per workspace (2000, pruned by the writer, non-reversible entries first).
6. **Log out only on 401/403.** Network errors and 5xx keep the session. A rejected token disconnects the shared provider and offers a fresh login; IndexedDB is never cleared on logout.
7. **Never wait on y-indexeddb's `whenSynced` directly; use `whenIdbLoaded`**, which gives up when the database cannot open.
8. **Image caches are byte-capped** (`ByteLru`): rendered bytes 64 MB, thumbnails 16 MB; asset cards load only near the viewport.
9. **Every pane renders inside an `ErrorBoundary` keyed on its tab**, and the app inside a root one.
10. **No `crypto.randomUUID` in client code** (not available over plain HTTP); use `uuid` v4.
