# UI audit: native and unthemed controls (2026-08-28)

Trigger: the finding severity picker (low / medium / high / critical) opened
as a bright white list in the middle of the dark Glass interface. Every
native control the browser draws itself was checked after that. The table
is the record of what was found and what changed.

| Where | What looked old | Fix |
|---|---|---|
| Whole app | No `color-scheme` was declared, so every popup the browser owns (select lists, date and colour pickers, number spinners, scrollbars) painted in the light scheme over dark surfaces | `:root { color-scheme: light }` and `.dark { color-scheme: dark }` in `src/index.css` |
| Finding properties (severity, type), edge type, timeline narrative filter, command-log host filter, editor inline selects, admin default workspace | Six native `<select>`s with the platform arrow and a white popup | Base `select` rule: `appearance: none`, the app's own chevron (SVG data URI, grey per scheme), `padding-right` so text clears it; `option` rows on the popover colour; the Glass field styling already covers background, border and radius |
| Graph layout sliders, screenshot blur sliders | Native `range` in the browser's default blue | `accent-color: hsl(var(--primary))` for `range`, `checkbox`, `radio`, `date` and `datetime-local` inputs |
| Profile colour, theme picker colour, heading colour swatches | Native `color` inputs with the platform bevel | Flat swatch: no padding, 1px border, small radius, card background |
| Admin panel: delete user, delete backup | `window.confirm`, a browser dialog outside the theme | `ConfirmDialog` (`src/components/ui/ConfirmDialog.tsx`): themed sheet in a body portal, destructive styling, Escape cancels |
| Assistant chat history: rename, delete | `window.prompt` and `window.confirm` | `ConfirmDialog` with an input for the rename, destructive confirm for the delete |
| Typst export (PDF, SVG) failures | `window.alert` | Dismissible red banner under the Typst toolbar (`exportError`) |
| Nmap import, Typst assets, profile import | Native file inputs | Already hidden behind themed buttons; no change |
| Typst preview pages | White page background | Intentional: it renders the paper |

Rule going forward (CLAUDE.md invariant 14): no `window.confirm`,
`window.prompt` or `window.alert`; use `ConfirmDialog` or an inline notice.
Native inputs are fine as long as `color-scheme` stays declared and the
base rules above are kept.
